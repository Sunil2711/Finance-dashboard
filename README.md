# My Money — iPhone-only PWA

Files:
- index.html
- manifest.webmanifest
- service-worker.js
- icon.svg

This is a static demo personal-finance dashboard. It stores only local demo/manual data in Safari localStorage.

## Publish from iPhone using GitHub Pages
1. In Safari, go to github.com and sign in.
2. Create a new public repository, for example `my-money-dashboard`.
3. Add/upload these four files to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Open the Pages URL GitHub provides.
8. In Safari, use Share > Add to Home Screen and enable Open as Web App.

Important: GitHub Pages is public. Do not put real bank credentials, account numbers, tokens, or private financial exports in the repository or source code.
